# Nofelet API Gateway

Web бэкенд для сервиса звонков, на Go.

## 🏗 Архитектура

Проект состоит из 6 основных компонентов:

### 1. Nofelet-Signaling
**Реализовано** ✅
- WebSocket сервер для обмена SDP offer/answer и ICE candidates
- Управление подключениями между клиентами

### 2. Nofelet-Chat
**Реализовано** ✅
- Чат для коммуникаций в комнатах

### 3. Nofelet-Web
**Реализовано** ✅
- REST API Gateway для управления пользователями и комнатами
- Статический хост для Web клиента
- Аутентификация и авторизация

### 4. Nofelet-UI
**Реализовано** ✅
- Простой ui на js + html + css
- Реализует WebRTC логику на чистом JS

### 5. Nofelet-Infra
**Реализовано** ✅
- Вся инфра хранится, версионируется тут

### 6. Nofelet-SFU
**В разработке** 🚧
- Медиасервер для маршрутизации аудио/видео потоков
- Поддержка групповых видеоконференций
- Адаптивная битрейт под клиентские устройства

# Описание Nofelet API Gateway
- REST API Gateway служит проксей для остального бекенда и отвечает за:
- Авторизацию пользователя
- Регистрацию нового пользователя
- Предоставляет комнаты для p2p звонков и конфколлы (конфколлы в разработке)

## 🚀 Быстрый старт

### Предварительные требования
- Go 1.25+

### Установка и запуск

```bash
# Клонирование репозитория
git clone git@github.com:MaximTretjakov/nofelet-web.git

# Сборка signaling сервера
make build_web

# Запуск signaling сервера
make run_web

```
